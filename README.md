# 💊 약찾GO | 의약품 재고 관리 및 조회 시스템

## 📌 프로젝트 개요

약사와 고객 모두를 위한 의약품 재고 관리 및 조회 서비스입니다.

### 🤔 문제 정의와 필요성

환자가 처방받은 약을 약국에서 구하지 못하면, 약사가 병원에 연락해 대체약 가능 여부를 확인하거나,

환자가 직접 다른 약국을 찾아다니거나 병원에 재방문해야 하는 불편함이 발생합니다.

약찾GO는 이러한 문제를 해결하기 위해

- 실시간 약국 재고 확인
- 대체 의약품 검색
- 약국 공지사항 제공

기능을 통해 환자의 불필요한 이동을 줄이고 접근성을 높였습니다.

### 👩‍⚕️ 약사 기능

- 약국 정보 관리 (약국명, 위치, 연락처)
- 공지사항 등록, 수정, 삭제
- 의약품 재고 관리 (신규 등록, 삭제, 입출고 기록 관리)
- 대시보드 제공

### 🧑‍💻 고객 기능

- 주변 약국 위치 조회
- 의약품 재고 조회
- 약국 공지사항/상세정보 확인
- 대체 의약품 검색
